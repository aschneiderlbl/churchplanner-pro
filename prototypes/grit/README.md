# Grit prototype

A clickable concept prototype of Grit, a phone app for finishing drafts by talking.

Nothing records your voice or calls a model. Notes, edits, research and model answers are scripted, and read-aloud uses the browser's built-in voice.

The page is a static site: open `index.html` or serve the folder with GitHub Pages. `vendor/preact.min.js` is [Preact](https://preactjs.com) 10.24.3 under the MIT license.
